# Project instructions

- This is an Android app written in Kotlin with Jetpack Compose and built with Gradle.
- Use the project's Gradle wrapper and Android SDK/JDK toolchain for verification. Gradle compilation, debug APK builds, and relevant tests or lint checks are allowed.
- Do not install or launch the app on a device or emulator, or start audio playback, unless explicitly requested. The user handles interactive and listening checks in Android Studio and on their device.
- C/C++ compile-only restrictions and the CLion MinGW tool path do not apply to this project's Kotlin/Android work.
